# 🎉 Event Management Application (EMA) – iOS App

## 📱 Overview
The **Event Management Application (EMA)** is an iOS-based mobile application designed to simplify the process of organizing, managing, and tracking events. It serves as a smart platform for both organizers and participants to connect, collaborate, and ensure seamless event execution — all from one app.

---

## 🚀 Features
- 🗓️ **Create & Manage Events:** Add, edit, or delete event details effortlessly.  
- 👥 **User Registration:** Register participants and maintain event-wise attendance.  
- 🔔 **Notifications:** Get instant updates and reminders for upcoming events.  
- 📸 **Gallery:** Upload and view images from past or ongoing events.  
- ☁️ **Real-Time Sync:** Firebase integration ensures instant data updates across users.  
- 🔐 **Secure Login:** Firebase Authentication for user login and registration.

---

---

## 🧩 Architecture
The app follows a **Model-View-Controller (MVC)** design pattern for maintainability and scalability.  
It leverages **Firebase** as a backend to handle authentication, data management, and cloud storage.

---

## 💡 Key Objectives
- Streamline event management for organizers and attendees.  
- Provide real-time updates and tracking features.  
- Offer a simple, clean, and intuitive user interface.  
- Enhance communication through notifications and integrated feedback.
